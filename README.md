# Tome

## by David Lilley

A virtual world where a series of rooms are described partly through 3D modelling and partly through prose. A contemplation upon the fragility of memory, showing the viewer the artist's past as depicted by the living spaces he once inhabited.

**Technical Director:** Thom McIntosh _- Alien Heart_

**Produced by:** e-2

**Viewing requirements:** Cosmo Player 2.0 plugin

## Layout

The original files are at the top of this repository. The current version of the site is in `docs/`, which is what GitHub Pages publishes. Summaries and transcripts of the Claude Code sessions are in `_sessions/`.
